## 📌 Rangkuman 3 Detik: Apa Itu SocialFeed?
**SocialFeed** adalah **aplikasi media sosial modern berbasis komunitas** (seperti perpaduan antara **Facebook Feed + X/Twitter + Facebook Groups**).

Di SocialFeed, pengguna bisa:
1. 📝 **Membuat Status & Postingan** (Teks, Foto HD, dan Video hingga 100MB).
2. 👍 **Berinteraksi** (Suka/Like dan Berkomentar pada postingan).
3. 👥 **Menjalin Pertemanan** (Kirim, terima, atau tolak permintaan teman).
4. 👨‍👩‍👧‍👦 **Bergabung dengan Grup** (Diskusi komunitas publik & privat).
5. 🔔 **Menerima Notifikasi** (Pemberitahuan real-time saat ada Suka, Komentar, atau Pertemanan baru).
6. 📱 **Menggunakan HP dengan Nyaman** (Tampilan khusus mobile dengan menu navigasi bawah ala aplikasi native).
